Lib baru Absolute Layout dan Sqlitedb
cara jalanin tanpa netbeans
  1. buka file explorer
  2. buka file kesiswaan, cari file jar didalam dist
  3. copy, lalu buka file manajemenData
  4. cari folder dist, paste file jar sebelumnya
  5. taruh juga file dbsekolah.db didalam folder dist tersebut.
maka susunan tampilannya akan sebagai berikut:

Dist-
  |--lib
  |--Aplikasi_kesiswaan.jar
  |--Aplikasi_manajemenData.jar
  |--dbsekolah.db
